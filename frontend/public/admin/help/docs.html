Welcome to Peekaboo Shades Admin

This documentation will help you understand and use all features of the Peekaboo Shades admin panel effectively.

Overview

The admin panel provides complete control over your custom window treatment business, including:

  • Product Management - Add, edit, and organize your window treatment products
  • Fabric Library - Manage fabrics, collections, and pricing tiers
  • Order Processing - Handle orders from placement to delivery
  • Customer Management - Track customers, reviews, and trade accounts
  • Analytics - Monitor sales, performance, and trends

Quick Start Guide

1. Set Up Your Products

Start by adding your product types (Roller Shades, Zebra Blinds, etc.) and configuring available options.

2. Configure Fabrics

Upload fabric swatches, set pricing tiers, and organize into collections.

3. Set Pricing Rules

Define base pricing, fabric tier multipliers, and hardware surcharges.

4. Configure Shipping

Set up shipping zones and rates for your delivery areas.

Admin Panel Navigation

The sidebar navigation is organized into logical sections:

  • Dashboard - Quick overview of key metrics
  • Products - Catalog management
  • Orders - Order processing and fulfillment
  • Customers - Customer and trade accounts
  • Marketing - Promotions and campaigns
  • Reports - Analytics and insights
  • Settings - System configuration
