Measuring Guide

Complete measurement instructions for all window treatment products

General Measurement Guidelines

Accurate measurements are essential for a perfect fit. Follow these guidelines for all window treatments.

Important Tips

  • Use a rigid measuring tape and ensure accuracy within 3mm
  • Take measurements at top, middle, and bottom positions
  • Always measure in centimeters for precision
  • Double-check all measurements before ordering

Mounting Types

Inside Mount

Blinds fit inside the window frame for a clean, built-in look.

  • Depth Requirement: Window depth (D) should be more than 6cm
  • Width: Measure W1, W2, W3 at top, middle, bottom
  • Select: The shortest measurement
Width of Blind = Width - 0.5cm
Height of Blind = Height

Outside Mount

Blinds mount on the wall above and around the window frame.

  • Note: Window frames protruding more than 1cm from wall are NOT suitable
  • Width: Measure window frame width
  • Height: Measure window frame height
Width of Blind = Width + 10cm
Height of Blind = Height + 15cm

Outdoor Shades Measurement

Outdoor shades require precise measurements for proper installation and wind resistance.

Inside Mount

  • Measure at top, middle, and bottom positions
  • Width: Use minimum frame width - 5mm
  • Height: Use minimum frame height - 5mm

Outside Mount

External dimensions based on series:

  • 105 Series: Width + 100mm, Height + 160mm
  • 125 Series: Width + 120mm, Height + 180mm
  • Double Layer: Width + 160mm, Height + 310mm

Panel Track Blinds Measurement

Panel track blinds are ideal for sliding doors, wide windows, and room dividers.

Important: Width fits from 45.8" to 220" (116cm to 559cm)

Inside Mount

  • Minimum depth: 4 1/8" (10.5cm)
  • Measure at least 3 points (top, mid, bottom)
  • Width: Use minimum measurement = Order Width = End-to-end width
  • Height: Measure net height of window

Note: Do not remove any size in width - installation clearance will be considered by factory.

Outside Mount

  • Measure window net width
  • Add 6" (15cm) total extension in width
  • Add 8" (20cm) total extension in height
Order Width = Net Width + 6"
Order Height = Net Height + 8"

Common Applications

  • Sliding Doors
  • Closet Doors
  • Window Shades
  • Room Dividers
